# UNP_PROJECT_REGRESSION_STEEL_INDUSTRY_ENERGY_CONSUMPTION_PREDICTION_USING_PYTHON
In collaboration with UNP, I developed a machine learning-based energy consumption prediction model using the Steel Industry Energy Consumption Dataset with 35,040 observations and 11 original variables.
Analysed energy consumption patterns across electrical, operational, and time-related factors such as reactive power, power factor, load type, hour, and day of the week.
Performed data pre-processing, exploratory data analysis, correlation analysis, and feature engineering.
Implemented Linear Regression, Decision Tree Regression, and Random Forest Regression models.
Evaluated models using MAE, MSE, RMSE, and R² across 70:30, 80:20, and 90:10 train-test splits.
Random Forest achieved the best overall performance with an R² of 0.9994 and low prediction errors using the 80:20 split.
Identified Lagging Current Reactive Power and Lagging Current Power Factor as the most influential features.
Demonstrated how machine learning regression can effectively predict energy consumption and support better monitoring, operational planning, and efficiency in energy-intensive steel manufacturing.
